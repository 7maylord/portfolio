# Alfred Olumide Adenigba Portfolio

Engineering portfolio built with Next.js, TypeScript, and Tailwind CSS.

## About

The portfolio for Alfred Olumide Adenigba — a full-stack, Rust, AI, and
blockchain engineer who moved into software from civil/geotechnical engineering.
That background drives the design: the site is a **geotechnical section drawing**
you descend through. The cursor is a surveyor's reticle that casts live dimension
lines and logs coordinates, elevation, and bearing in a title-block HUD; projects
are presented as core samples logged at depth.

## Local development

